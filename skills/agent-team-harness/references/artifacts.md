# Task Artifacts

Each substantial task should create a packet under `work/<slug>/`.

## `brief.md`

- task objective
- current facts
- constraints
- open questions

## `plan.md`

- ordered implementation steps
- verification steps
- explicit non-goals

## `implementation.md`

- key edits made
- commands run
- outcomes observed

## `review.md`

- findings first
- open questions
- residual risks

## `reflection.md`

- what broke
- what should become a rule, fixture, or automation
- what to do next
