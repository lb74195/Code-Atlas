# Workflow

## 1. Observe

- inspect `AGENTS.md`, the active task packet, and the relevant generated `ai/` files
- identify the current failure, gap, or hypothesis
- capture only the facts needed for this task

## 2. Orient

- check architecture docs, config, fixtures, and upgrade advisories
- constrain the task to one verifiable increment
- note heuristics or uncertainty before implementation

## 3. Decide

- choose one path with explicit tradeoffs
- define the verification steps up front
- prefer a local proof over a broad promise

## 4. Act

- implement
- run verification
- regenerate affected artifacts
- update the implementation log

## 5. Reflect

- perform a reviewer pass
- write reflection and backlog follow-ups
- tighten repository rules if a failure pattern repeated
